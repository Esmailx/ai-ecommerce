# AI E-Commerce

# مشروعي لنيل درجة البكالوريوس في تقنية المعلومات (IT)– جامعة العلوم والتكنولوجيا.
ويهدف هذا المشروع إلى دمج تقنيات الذكاء الاصطناعي مع متجر إلكتروني لتحسين تجربة المستخدم وتطوير عمليات البيع والإدارة.
اليمن - امانة العاصمة صنعاء.

---

## نبذة عن المشروع
يهدف هذا المشروع إلى تطوير وتدريب نماذج الذكاء الاصطناعي التالية:  
- Association Rules  
- Classification  
- Time Series  

ثم دمجها مع متجر إلكتروني مبني على WordPress، وذلك عبر تطوير واجهة برمجية (API) باستخدام Flask وPython.

### الميزات الرئيسية:
- تحليل بيانات المتجر الإلكتروني لاستخراج الأنماط والسلوكيات.  
- توصيات شراء للمنتجات المترابطة باستخدام خوارزميات Association Rules.  
- توصيات مخصّصة للزبائن بناءً على معلوماتهم وسلوكهم باستخدام Classification.  
- توقع المبيعات المستقبلية عبر نماذج Time Series للتنبؤ بالاتجاهات القادمة.
